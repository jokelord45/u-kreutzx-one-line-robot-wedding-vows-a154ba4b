A single line of wedding vows for a robot couple — a real promise, with a
specific machine detail and a twist that pays off in the last few words.

## Run it

```sh
node main.ts
```

The program writes the vow to `/output/entry.txt` (one line, 1–160
characters). Node 22, standard library only, no network, no secrets.
